About this source snapshot & how to read the map

This map contains available cached JavaScript sources from expressjs/express master. The observed history head is 023767fe9872e029271df1418f73401bff20ff40; these cached files are not verified against that checkout. Some files are unavailable. Preview whitespace may be normalized. Arrows point from a file to the file it imports. Only literal, relative require calls become edges; npm and built-in modules appear as external dependencies. Dynamic imports are not resolved.

Core covers lib/ and the root entry point. Express now uses external router and middleware packages: the Router category covers routing example directories; Middleware covers route-middleware, error, and cookie-sessions examples. Category filters and search combine. Click a connected file in the inspector to follow it, or drag the graph to pan.
